# Terrainy documentation

Start with the [README](../README.md) to install Terrainy and generate your
first scene. The documentation is deliberately organized by user task.

| Guide | Use it for |
| --- | --- |
| [Editor painting & sculpting](EDITOR_PAINTING.md) | Brush stamps, organic height edits, materials, Undo/Redo, collision and persistence |
| [Procedural grids](PROCEDURAL_GRID.md) | Layout previews, multi-tile Apply, deterministic seams and cancellation |
| [Architecture](ARCHITECTURE.md) | Module responsibilities, storage, compatibility and editor/runtime boundary |
| [Validation](VALIDATION.md) | Headless regression commands and manual Godot 4.7 acceptance |
| [Terrain3D performance review](TERRAIN3D_PAINTING_REVIEW.md) | Findings about brush optimization and remaining limitations |
| [Design notes](TERRAIN_DESIGN_NOTES.md) | Compact product principles and future work |

The main workflow is exclusively in the Godot 3D editor. Legacy runtime
generation and water-related resources are optional and outside the default
editor toolchain.

Contributors: see [AGENTS.md](../AGENTS.md) for ownership and
[CONTRIBUTING.md](../CONTRIBUTING.md) for the development workflow.
